### 2. 🤖 EduPulse AI

**AI-Powered Learning Assistant Using Retrieval-Augmented Generation**

An AI-powered learning application that allows students to upload educational PDFs, ask questions about their study materials and generate learning resources.

**Key Features:**
- 📄 Upload and process PDF documents
- 🧠 Text extraction and intelligent document chunking
- 🔎 Semantic search using sentence-transformer embeddings
- 🗄️ Vector storage and retrieval using ChromaDB
- 💬 Context-aware question answering using RAG
- 📚 Generate quizzes from uploaded study materials
- 🃏 Create interactive flashcards
- 📖 Provide page references for retrieved information
- 🤖 AI-powered content generation using OpenAI
- 🌐 Deployed using Streamlit Community Cloud

**Tech Stack:** `Python` `Streamlit` `OpenAI` `ChromaDB` `RAG` `Sentence Transformers` `PyPDF`
